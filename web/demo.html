    System Design

    Architecture

    Modular multi-stage analysis pipeline engineered for zero-trust execution and defense-in-depth.

    0 – 20
    No issues observed

    No suspicious activities detected during the short execution window.

    21 – 60
    Suspicious

    Anomalous behavior observed (e.g. process bursting, high memory, or unmapped writes).

    61 – 100
    Malicious

    Dangerous containment breaches (e.g. blocked seccomp syscalls, fork exhaustion).

    Applications

    Built for untrusted execution

    Designed for developers, operations, and security researchers handling unknown code.

    Untrusted CLI Binaries

    Pre-screen third-party tools, downloads, and binaries before executing them on host machines.

    Build & CI/CD Pipelines

    Automatically audit external dependencies, compiled artifacts, and test runners in isolated sandboxes.

    Security Triage

    Rapidly assess suspicious payloads, malware samples, or exploits with bounded resource consumption.

    Limits & Honesty
    • Short observation window: Attacks designed to sleep or delay execution beyond the monitoring window may not exhibit behaviors.
    • Linux only: Built strictly around Linux kernel primitives (user/pid/mount/net namespaces, cgroups v2, seccomp-bpf).
    • Not a replacement for antivirus: Sentry analyzes runtime behavior and containment; it complements, rather than replaces, traditional signature AV.
